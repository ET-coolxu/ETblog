# 个人博客第二版产品需求：专栏

本文只写相对 [v1](v1.md) 的增量。v1 已封存，本文没提到的一律以 v1 为准。后台界面仍以 [后台工作台 V2](v2-admin.md) 为准，本文不改后台。

需求来源：原型仓库 `columns/prd.md`（2026-10-23 用户确认「都按推荐」）。原型 2026-10-23 确认（ETblog-prototypes `0269bf4`，评审见原型仓库 `columns/review.md`）。视觉以 [`docs/design/columns/spec.md`](../design/columns/spec.md) 为准。实现前先读 [`.cursor/rules/project.mdc`](../../.cursor/rules/project.mdc)。

## 1. 概述

新增三个内容栏目，内容来自作者的 AI bot 舰队产出，经作者审稿后发布：

- **折腾记录**：长文。
- **AI 助手舰队**：`/fleet`，介绍各 bot 的角色与协作。
- **Bot 周报**：每周五一篇。

导航只加一项「专栏」→ `/columns`。周报与资讯不进首页「最新」。

栏目就是标签，不新增内容类型、不改 frontmatter、不改文章状态机。

## 2. 已确认决策

- 导航加「专栏」一项，位置在「文章」与「标签」之间，不做下拉。
- `/columns` 三栏各一张卡片：栏目名、篇数、一句简介、最近 3 篇、「全部 →」链到标签页。舰队卡片不列文章，改为更新日期、bot 数和「查看舰队 →」，右上链接叫「往期 →」。资讯在页底弱化一块，不做卡片。
- 首页「最新」按标签排除，默认排除 `Bot周报`、`资讯`、`舰队`，清单可配置。
- `/fleet` 取标签 `舰队` 的最新一篇已发布文章；每月一篇，有 bot 增删时加一篇。
- 舰队文章有固定写法（见 4.2）；页首流程图是静态图片，不做交互。
- `/fleet` 正文栏宽与文章页相同：52rem（832px，`--measure`）。
- 路由用 `/fleet`；原型预览路径 `/columns/fleet/` 不作为正式路由。
- 专栏文章一律先存草稿，作者审完才发布；遵守 4.3 的脱敏规则。
- 不做：下拉菜单、评论、订阅、按栏目 RSS、交互流程图、后台栏目管理、改 v1 文章页。

## 3. 用户故事

- 访客在顶栏点「专栏」，看到折腾记录、AI 助手舰队、Bot 周报三块和底部资讯，每块有最近几篇和「全部」入口。
- 访客打开 `/fleet`，先看到一张协作流程图，再按 bot 逐个读「角色」「协作对象」和简短说明。
- 访客在首页只看到精选和常规文章，周报与资讯不出现在「最新」里，但能在 `/posts`、标签页、搜索、RSS 里找到。
- 机器客户端（博客管理员例程）每周五用 `/api/v1/posts` 存一篇 `Bot周报` 草稿；作者在后台审稿后发布。

## 4. 内容约定

### 4.1 标签

| 栏目 | 标签 |
|---|---|
| 折腾记录 | `折腾记录` |
| AI 助手舰队 | `舰队` |
| Bot 周报 | `Bot周报` |
| 资讯 | `资讯`（v1 5.4 已有约定） |

标签按原文精确匹配。与 v1 5.4 相同，这是内容约定，不是接口校验条件。

### 4.2 舰队文章写法

- 正文第一张图为协作流程图，webp 或 png（v1 禁止 svg 上传）。mermaid 只作源稿，不进正文。
- 每个 bot 一个 `##`，标题为 bot 现名。其下紧跟两条列表 `- **角色**：…`、`- **协作对象**：…`（多个用顿号），再接 1–3 句说明。不用 h3、不用表格。示例：

  ```md
  ## 示例助手 A

  - **角色**：总管，负责派发和汇总
  - **协作对象**：示例助手 B、示例助手 C

  一到三句说明。
  ```

- 流程图只放这一张，放在开头一段说明之后；浅灰底和细边框画进图里。站点不显示图注，说明写进 alt。
- `date` 为本次更新日期。

站点不校验这个格式，只按普通 Markdown 渲染。

### 4.3 脱敏

1. 不写 token、key、密码、webhook、Authorization 头。
2. 不写微信号、邮箱、手机号、IP、路径里的用户名。
3. 不写健康、薪资、求职等私人信息。
4. 不放私有 Notion / 私有仓库链接，不写 bot 内部 id。
5. 截图打码。
6. 不写 VPS 代理服务；端口、容器名、路径、回滚 tag、内部域名用示例值。
7. 不贴原始日志，只写错误类型和结论。

### 4.4 草稿

机器客户端只存草稿，不调用发布，也不改已发布文章。舰队页更新一律新建一篇。

## 5. 站点配置（新增）

- `HOME_EXCLUDE_TAGS`：可选，英文逗号分隔的标签名。默认 `Bot周报,资讯,舰队`；显式留空则不排除。与 v1 5.3 同样不得写死在组件里。

## 6. 公开页面（增量）

### 导航

右侧改为：文章、专栏、标签、关于，细竖线后接搜索与主题。路由为 `/columns` 或 `/fleet` 时「专栏」为选中态。无下拉，不收进菜单。窄屏只收间距：宽度 < 420px 导航间距 12px；< 380px 品牌名字号降一档、间距再收（具体见设计稿）；360px 宽必须完整显示且无横向滚动。

### `/`

v1 第 6 节「最新」规则追加：排除带 `HOME_EXCLUDE_TAGS` 中任一标签的文章，排除后仍最多取 6 篇（往后补足），且仍不与精选重复。精选不受排除规则影响。「/ 全部 N 篇」「当前显示 x / N 篇」里的 N 仍为全部已发布篇数（含被排除的）。

### `/columns`（新增）

- 页头：「专栏」+ 一句说明。
- 依次三张卡片：折腾记录、AI 助手舰队、Bot 周报；页底资讯一块（弱化，无卡片框）。
- 卡片浅色底不变（`--panel`），边框比列表分隔线深一档（新 token `--card-line` #d6d2c9；深色模式不变）。
- 卡片标题后显示「· N 篇」，N 为该标签已发布总数。
- 折腾记录、Bot 周报、资讯：最近 3 篇已发布，按 `date` 降序；「全部」链 `/tags/{编码后标签}`。
- AI 助手舰队：简介、当前 `/fleet` 所用文章的日期与 bot 数（`##` 个数）、「查看舰队 →」链 `/fleet`；右上「往期 →」链 `/tags/舰队`（其余卡片和资讯为「全部 →」）。无已发布舰队文章时显示「舰队介绍还在整理中。」，两个链接都不显示。
- 某块无已发布文章：篇数为 0，显示「还没有文章，第一篇在路上。」，不显示「全部」。
- 只含已发布。文档标题 `专栏 · {SITE_NAME}`。

### `/fleet`（新增）

- 渲染标签 `舰队` 中 `date` 最新的一篇已发布文章，正文渲染、目录（h2）同 `/posts/[slug]`，正文栏宽 52rem（832px）与文章页一致。页首「← 专栏」、更新日期与 bot 数、标题固定为「AI 助手舰队」；页尾「往期 →」链 `/tags/舰队`。
- 每个 bot 下的「角色」「协作对象」列表比正文小一号、颜色弱化，只在本页生效，不改全站正文样式。
- 不计 PV（PV 仍只记 `/posts/[slug]`，v1 第 8 节不变），也不进 [访问记录](v3-visits.md)。`/columns` 同样不计。
- 无已发布舰队文章：中文空状态「舰队介绍还在整理中。」，不 404、不 500。
- 该文章的 `/posts/[slug]` 照常可访问。文档标题 `AI 助手舰队 · {SITE_NAME}`。

### 发现与 SEO

- `sitemap.xml` 增加 `/columns`、`/fleet`。
- RSS、搜索、`/posts`、`/tags` 行为不变，专栏文章照常出现。
- 新文章发布后，`/columns`、`/fleet`、`/` 与其它公开页一样 `revalidatePath`，不整站重建。

## 7. 后台

不变。不加栏目管理页。

## 8. 明确不做（v2）

导航下拉 / 二级菜单、评论、邮件订阅、按栏目 RSS、交互式流程图、正文 mermaid 渲染、后台栏目管理、栏目封面、改 v1 文章页 / `/posts` / 标签页 / 搜索 / RSS 行为、新增 frontmatter 字段。
