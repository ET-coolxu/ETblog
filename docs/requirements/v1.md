# 个人博客第一版产品需求

本文是第一版的**唯一产品说明**。实现以本文为准；任务切片见 `docs/agent-prompts/`。改需求先改本文，再改对应提示词，不要只在聊天里改。

实现前先读 [`.cursor/rules/project-conventions.mdc`](../../.cursor/rules/project-conventions.mdc)。

## 1. 概述

面向中文读者的可自托管个人博客。作者用 Markdown 写技术/生活笔记，也可在浏览器里改稿、插图后发布。站点跑在自己的 VPS 上，不绑定 Vercel。

站名、作者署名为占位配置 `SITE_NAME`、`AUTHOR_NAME`，上线前再改，不要写死在组件里。

## 2. 角色

- **访客**：读已发布文章、按标签浏览、搜索、订阅 RSS。不登录。
- **管理员**：仅一人。密码登录后写文章、改草稿、上传图片、看访问统计。

## 3. 已确认决策

- 文章以 Markdown 文件为**唯一信源**；后台只是这些文件的编辑器，禁止再存一份数据库文章副本。
- 第一版范围：公开阅读、搜索、代码高亮、目录、暗色模式、访问统计、后台发文（含图片）。
- 后台第一版**只管文章**（新建、编辑、草稿、发布）和图片上传。不删除文章、创建后不可改 slug、关于页只用本地文件。
- 不做：评论、邮件订阅、多用户、独立 Umami/Postgres、CDN、文章内 JSX、正文原始 HTML。

## 4. 用户故事

- 访客打开首页，能看到站点简介和最新已发布文章，点进正文阅读。
- 访客在列表/标签页浏览已发布文章；草稿不可见。
- 访客在正文看到目录、代码高亮、封面（若有）、上一篇/下一篇。
- 访客用中文关键词搜索标题、摘要、正文，得到已发布结果。
- 访客切换浅色/深色（默认跟随系统），刷新后保持。
- 访客通过 RSS、sitemap 发现文章；分享链接有合理标题、描述和 OG 图。
- 管理员登录后台，新建文章（此时设定 slug），写 Markdown，上传图片并插入正文，存草稿或发布。
- 管理员再次打开已有文章继续改，发布后前台立刻可见（`revalidatePath`，不整站重建）。
- 管理员在统计页看到各文 PV 和热门文章。
- 管理员不能删除文章、不能改已有 slug、不能在后台改关于页。

## 5. 内容模型

### 5.1 文章

路径：`content/posts/{slug}.md`

Frontmatter：

- `title`：必填，字符串
- `date`：必填，ISO 日期 `YYYY-MM-DD`
- `tags`：字符串数组，可空
- `summary`：字符串；列表、RSS、SEO 用。空则截取正文前约 120 字
- `cover`：可选，站点内路径，如 `/uploads/2026/08/x.webp`
- `draft`：布尔，默认 `false`。为 `true` 时：不出现在公开列表；访客打开详情为 404；不进搜索、RSS、sitemap；不计 PV
- `featured`：布尔，默认 `false`。为 `true` 时首页优先展示

规则：

- `slug` 仅 `[a-z0-9-]+`，创建时确定，之后不可改；文件名与 slug 一致。读写路径时必须防止 `..` 等路径穿越。
- 标签展示用原文；标签 URL 使用编码后的标签名。
- 正文为 Markdown + GFM（表格、任务列表、删除线、自动链接）。不允许 JSX/React 组件，不开启原始 HTML。
- 图片文件：`public/uploads/{yyyy}/{mm}/`，正文写作 `![说明](/uploads/...)`。

### 5.2 关于页

路径：`content/pages/about.md`。仅本地编辑，第一版后台不提供入口。文件缺失时关于页显示明确空状态，不要 500。

### 5.3 站点配置

通过环境变量或站点配置读取，禁止在 UI 组件中写死：

- `SITE_NAME`、`AUTHOR_NAME`、`SITE_URL`
- `ADMIN_PASSWORD`、`SESSION_SECRET`
- `ADMIN_USER`（可选，默认 `admin`）

## 6. 公开页面

导航：站名、文章、标签、关于、搜索、主题切换。页脚：作者占位、RSS 链接。界面文案全程中文。

### `/`

- 简介来自站点配置占位文案，不是关于页全文。
- 展示 `featured: true` 的已发布文章；然后展示最新已发布，最多 6 篇。无精选则只显示最新。

### `/posts`

- 已发布列表，每页 10 篇，按 `date` 降序。
- 支持 `?tag=` 筛选。
- 无文章时显示空状态，不要空白页。

### `/posts/[slug]`

- 展示标题、日期、标签、封面（若有）、估算阅读时间（中文约 300 字/分钟）、正文。
- 目录取 h2/h3：桌面随滚动高亮，移动端折叠。这是阅读页的签名元素，不要用大面积 Hero 替代。
- 代码块高亮（Shiki）。
- 上一篇/下一篇：仅已发布，按日期。
- 未知 slug，或草稿被访客打开：404。

### `/tags`

标签及对应已发布文章数。无标签时空状态。

### `/tags/[tag]`

该标签下已发布列表。无匹配时 404 或空状态（实现时选一种并在空状态写明）。

### `/about`

渲染关于页 Markdown。缺文件时说明「尚未填写关于页」。

### `/search`

- 搜索标题、摘要、正文。
- 必须能搜中文（CJK n-gram 或等价方案，不能只按空格分词）。
- 结果展示标题 + 摘要片段；无结果有说明。
- 只返回已发布文章。

### 发现与 SEO

- `/feed.xml`：最近 20 篇已发布，**全文**。
- `sitemap.xml`：静态页 + 已发布文章。
- `robots.txt`：允许抓取公开页。
- 文档标题：`{页面} · {SITE_NAME}`。
- 文章分享：`summary` 作描述；有封面用封面，否则用默认 OG 图。

## 7. 后台页面

除 `/admin/login` 外，`/admin/*` 未登录须重定向到登录页。上传接口必须鉴权。

### `/admin/login`

密码登录（`ADMIN_PASSWORD`）。用户名用 `ADMIN_USER`，默认 `admin`。密码错误给出笼统提示，不区分用户是否存在。

### `/admin`

全部文章（含草稿），标明草稿/已发布。入口：写文章、统计。无删除按钮。

### `/admin/posts/new`

- 填写 slug（仅创建时，此后只读）、frontmatter、正文。
- 分栏 Markdown 预览。
- 拖拽或粘贴上传图片，插入 `![说明](/uploads/...)`。
- 操作：保存草稿、发布。

### `/admin/posts/[slug]`

编辑已有文章。slug 只读。无删除按钮。不存在的 slug：后台 404。

### `/admin/stats`

总 PV、每篇文章 PV、热门 Top 10（仅已发布）。不对访客展示。

### `/admin/logout`

清除 session 并回到登录页。

### 图片上传

- 允许：png、jpg、jpeg、webp、gif。
- 单文件最大 5MB。
- 禁止 svg。
- 失败时后台显示原因。

## 8. 访问统计

- 访客成功打开已发布正文时，服务端记 1 次 PV。
- 带管理员 session 的请求不记。
- 数据存在应用内 SQLite，不另外部署分析服务。

## 9. 非功能

- 阅读优先：克制衬线标题、清晰正文、充足行宽；暗色模式默认跟随系统，可手动切换，刷新保持，避免先闪浅色。
- 安全：slug 防路径穿越；Markdown 不渲染原始 HTML；管理员路由与上传均需登录；session 为 httpOnly。
- 部署：`output: 'standalone'` + Docker Compose + Caddy HTTPS；数据卷持久化 `content/`、`public/uploads/`、SQLite 目录。响应头避免反向代理缓冲流式输出（如 `X-Accel-Buffering: no`）。
- 发文后 `revalidatePath`，不要靠整站重建让新文章可见。

## 10. 明确不做（第一版）

评论、邮件订阅、多用户、删除文章、修改 slug、后台编辑关于页、独立 Umami/Postgres、CDN、文章内 JSX、正文原始 HTML。

## 11. 验收清单

### 公开阅读

- [ ] 首页展示简介、精选（若有）、最新已发布（最多 6 篇）
- [ ] `/posts` 分页（每页 10）、可按标签筛选；草稿不出现
- [ ] `/posts/[slug]` 渲染 Markdown：GFM、Shiki、封面、阅读时间、h2/h3 目录、上一篇/下一篇
- [ ] 访客打开草稿或不存在 slug 得到 404
- [ ] `/tags`、`/tags/[tag]`、`/about` 行为符合第 6 节；关于页缺文件不 500
- [ ] 导航与页脚文案为中文；站名/作者来自配置占位，未写死

### 搜索 / SEO / 主题 / 统计

- [ ] 中文关键词能搜到标题、摘要或正文；只返回已发布；无结果有说明
- [ ] 浅色/深色可切换，默认跟随系统，刷新保持
- [ ] `/feed.xml` 最近 20 篇已发布全文；有 sitemap、robots、OG、标题格式 `{页面} · {SITE_NAME}`
- [ ] 访客打开已发布正文记 PV；管理员访问不记；`/admin/stats` 可见总 PV、分文 PV、热门 Top 10

### 后台

- [ ] 未登录访问 `/admin` 其他页会到登录页；错误密码有提示
- [ ] 可新建文章（此时设定 slug）、保存草稿、发布；可再编辑；发布后前台不重建即可看见
- [ ] 可上传允许类型的图片并插入正文；超限或 svg 失败且有原因
- [ ] 无删除按钮；编辑页 slug 只读；无关于页编辑入口

### 工程与部署

- [ ] 运行时读 `content/`，未把文章做成 `app/` 下的 MDX 路由
- [ ] Docker Compose + Caddy 配置齐全；`content/`、`public/uploads/`、SQLite 目录可持久化（本地至少能按文档起服务或写明缺口）
