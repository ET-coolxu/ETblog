# 个人博客第一版产品需求

本文是第一版的**唯一产品说明**。实现以本文为准；任务切片见 `docs/agent-prompts/`。改需求先改本文，再改对应提示词，不要只在聊天里改。

实现前先读 [`.cursor/rules/project-conventions.mdc`](../../.cursor/rules/project-conventions.mdc)。

## 1. 概述

面向中文读者的可自托管个人博客。作者用 Markdown 写技术/生活笔记，也可在浏览器里改稿、插图后发布。站点跑在自己的 VPS 上，不绑定 Vercel。

站名、作者署名为占位配置 `SITE_NAME`、`AUTHOR_NAME`，上线前再改，不要写死在组件里。

## 2. 角色

- **访客**：读已发布文章、按标签浏览、搜索、订阅 RSS。不登录。
- **管理员**：仅一人。密码登录后写文章、改草稿、存档、删除、上传图片、看访问统计。

## 3. 已确认决策

- 文章以 Markdown 文件为**唯一信源**；后台只是这些文件的编辑器，禁止再存一份数据库文章副本。
- 第一版范围：公开阅读、搜索、代码高亮、目录、暗色模式、访问统计、后台发文（含图片）。
- 后台只管文章（新建、编辑、草稿、发布、存档、删除）和图片上传。创建后不可改 slug、关于页只用本地文件。
- 不做：评论、邮件订阅、多用户、独立 Umami/Postgres、CDN、文章内 JSX、正文原始 HTML、回收站、级联删除上传图片。

## 4. 用户故事

- 访客打开首页，能看到站点简介和最新已发布文章，点进正文阅读。
- 访客在列表/标签页浏览已发布文章；草稿与存档不可见。
- 访客在正文看到目录、代码高亮、封面（若有）、上一篇/下一篇。
- 访客用中文关键词搜索标题、摘要、正文，得到已发布结果。
- 访客切换浅色/深色（默认跟随系统），刷新后保持。
- 访客通过 RSS、sitemap 发现文章；分享链接有合理标题、描述和 OG 图。
- 管理员登录后台，新建文章（手填 slug，第一次保存后写成「手填-全站序号」），写 Markdown，上传图片并插入正文或封面，存草稿或发布。
- 管理员再次打开已有文章继续改，发布后前台立刻可见（`revalidatePath`，不整站重建）。
- 管理员可将已发布改为草稿或存档；存档后须先改为草稿才能再发布。任意状态均可删除文章。
- 管理员在统计页看到各文 PV 和热门文章。
- 管理员不能改已有 slug、不能在后台改关于页。

## 5. 内容模型

### 5.1 文章

路径：`content/posts/{slug}.md`

Frontmatter：

- `title`：必填，字符串
- `date`：必填，ISO 日期 `YYYY-MM-DD`
- `tags`：字符串数组，可空
- `summary`：字符串；列表、RSS、SEO 用。空则截取正文前约 120 字
- `cover`：可选。站内路径（如 `/uploads/2026/08/x.webp`）或 `https://` 外链。拒绝 `http://`、协议相对 `//`、`javascript:`、`data:`。外链图依赖对方站点；列表与正文用原生 `<img>` 显示（不走 `next/image`）。
- `draft`：布尔，默认 `false`。为 `true` 时：不出现在公开列表；访客打开详情为 404；不进搜索、RSS、sitemap；不计新 PV
- `archived`：布尔，默认 `false`。为 `true` 时：对访客的可见性与草稿相同（列表不可见、直链 404、不进搜索/RSS/sitemap、不计新 PV）。与草稿不是同一状态：存档表示已完成但撤出前台，后台标明「已存档」，不能直接点「发布」
- `featured`：布尔，默认 `false`。为 `true` 时首页优先展示；仅已发布生效，草稿与存档忽略

状态（三选一，写入时不得 `draft` 与 `archived` 同时为 true；读盘时若两字段都为 true，对外按存档处理、后台显示已存档）：

| 状态 | frontmatter | 访客 | 后台可做的状态变更 |
|---|---|---|---|
| 草稿 | `draft: true`，无 `archived` | 不可见、直链 404 | 保存草稿、发布、删除。无存档入口 |
| 已发布 | 两者皆无或皆 false | 公开 | 保存更新、改为草稿、存档、删除 |
| 已存档 | `archived: true`，无 `draft` | 不可见、直链 404 | 保存（仍为存档）、改为草稿、删除。禁止直接发布 |

流转：草稿 → 已发布；已发布 → 草稿；已发布 → 已存档；已存档 → 草稿 → 已发布。禁止已存档 → 已发布。

规则：

- `slug` 仅 `[a-z0-9-]+`。新建时手填；**第一次保存**必须追加全站递增数字 ID，文件名为 `{手填}-{n}`（例如填 `notes` 存成 `notes-1`，下一篇填 `hello` 存成 `hello-2`）。序号从磁盘上**现存** `content/posts/*.md` 文件名尾部 `-{数字}` 取最大值 + 1，没有则从 1 起；旧文不改名。已删除文件不再占用序号、不进已删黑名单。不按前缀试探空闲名，不另建 ID 表，也不提供「指定完整旧 slug」的入口。因此删掉中间序号（如 `notes-1` 而 `hello-5` 仍在）不会让下一篇自动变成 `notes-1`；只有当前最大序号被删时，下一篇才会再次用到该数字。若分配到的 `{手填}-{n}` 文件已不存在，允许写入（即重用已删除的完整 slug）。创建后不可改 slug。读写路径时必须防止 `..` 等路径穿越。
- 删除文章：删除 `content/posts/{slug}.md` 以及该 slug 的 PV 行；**不**删除 `public/uploads/` 中的图片（封面与正文引用都保留在磁盘）。删除前须中文确认，不可恢复。任意状态（草稿、已发布、已存档）都可删。删除后 `revalidatePath`。
- 标签展示用原文；标签 URL 使用编码后的标签名。
- 正文为 Markdown + GFM（表格、任务列表、删除线、自动链接）。不允许 JSX/React 组件，不开启原始 HTML。
- 图片文件：`public/uploads/{yyyy}/{mm}/`，磁盘名保持时间戳清洗。正文写作 `![说明](/uploads/...)`；编辑器插入时 alt 用占位「图片」，由作者改成具体说明。

### 5.2 关于页

路径：`content/pages/about.md`。仅本地编辑，第一版后台不提供入口。文件缺失时关于页显示明确空状态，不要 500。

### 5.3 站点配置

通过环境变量或站点配置读取，禁止在 UI 组件中写死：

- `SITE_NAME`、`AUTHOR_NAME`、`SITE_URL`
- `ADMIN_PASSWORD`、`SESSION_SECRET`
- `ADMIN_USER`（可选，默认 `admin`）

## 6. 公开页面

导航：站名、文章、标签、关于、搜索、主题切换。页脚：作者占位、RSS 链接。界面文案全程中文。

### `/`

- 简介来自站点配置占位文案，不是关于页全文。
- 展示 `featured: true` 的已发布文章；然后展示最新已发布，最多 6 篇。无精选则只显示最新。

### `/posts`

- 已发布列表，每页 10 篇，按 `date` 降序。
- 支持 `?tag=` 筛选。
- 无文章时显示空状态，不要空白页。

### `/posts/[slug]`

- 展示标题、日期、标签、封面（若有）、估算阅读时间（中文约 300 字/分钟）、正文。
- 目录取 h2/h3：桌面随滚动高亮，移动端折叠。这是阅读页的签名元素，不要用大面积 Hero 替代。
- 代码块高亮（Shiki）。
- 上一篇/下一篇：仅已发布，按日期。
- 未知 slug，或草稿 / 存档被访客打开：404。

### `/tags`

标签及对应已发布文章数。无标签时空状态。

### `/tags/[tag]`

该标签下已发布列表。无匹配时 404 或空状态（实现时选一种并在空状态写明）。

### `/about`

渲染关于页 Markdown。缺文件时说明「尚未填写关于页」。

### `/search`

- 搜索标题、摘要、正文。
- 必须能搜中文（CJK n-gram 或等价方案，不能只按空格分词）。
- 结果展示标题 + 摘要片段；无结果有说明。
- 只返回已发布文章。

### 发现与 SEO

- `/feed.xml`：最近 20 篇已发布，**全文**。
- `sitemap.xml`：静态页 + 已发布文章。
- `robots.txt`：允许抓取公开页。
- 文档标题：`{页面} · {SITE_NAME}`。
- 文章分享：`summary` 作描述；有封面用封面，否则用默认 OG 图。

## 7. 后台页面

除 `/admin/login` 外，`/admin/*` 未登录须重定向到登录页。上传接口必须鉴权。

### `/admin/login`

密码登录（`ADMIN_PASSWORD`）。用户名用 `ADMIN_USER`，默认 `admin`。密码错误给出笼统提示，不区分用户是否存在。

### `/admin`

全部文章（含草稿与存档），标明草稿 / 已发布 / 已存档。入口：写文章、统计。可删除（须确认）。

### `/admin/posts/new`

- 填写 slug（仅创建时；第一次保存后显示最终 `{手填}-{序号}`，此后只读）、frontmatter、正文。
- 分栏 Markdown 预览。
- 封面可选：选图上传写入 `/uploads/...`，或手填站内路径 / `https://` 外链。有合法封面时立刻显示预览；外链加载失败给出中文说明，不要裂图空白。
- 拖拽或粘贴上传图片，插入 `![图片](/uploads/...)`（alt 默认可改）。
- 操作：保存草稿、发布。新建页无存档、无删除。

### `/admin/posts/[slug]`

编辑已有文章。slug 只读。不存在的 slug：后台 404。按当前状态提供操作（均须登录、服务端校验，不能只靠藏按钮）：

- 草稿：保存草稿、发布、删除。无存档。
- 已发布：保存（仍为已发布）、改为草稿、存档、删除。
- 已存档：保存（仍为已存档）、改为草稿、删除。无「发布」、无再次存档。

存档与删除前给出中文确认。存档后访客直链 404。删除后回到 `/admin`。

### `/admin/stats`

总 PV、每篇文章 PV、热门 Top 10（仅已发布）。不对访客展示。存档与草稿不进分文列表和热门。删除文章时删除该 slug 的 PV 行；存档不删 PV（总 PV 仍含这些历史，直到删文）。新文章若重用已删 slug，PV 从 0 计。

### `/admin/logout`

清除 session 并回到登录页。

### 图片上传

- 允许：png、jpg、jpeg、webp、gif。
- 单文件最大 5MB。
- 禁止 svg。
- 磁盘文件名保持时间戳 + 清洗后的原名；不要用原始文件名当正文 alt。
- 失败时后台显示原因。

## 8. 访问统计

- 访客成功打开已发布正文时，服务端记 1 次 PV。
- 带管理员 session 的请求不记。
- 草稿与存档不计新 PV。
- 数据存在应用内 SQLite，不另外部署分析服务。
- 删除文章时删除对应 `post_views` 行；不删上传图片。

## 9. 非功能

- 阅读优先：克制衬线标题、清晰正文、充足行宽；暗色模式默认跟随系统，可手动切换，刷新保持，避免先闪浅色。
- 安全：slug 防路径穿越；Markdown 不渲染原始 HTML；管理员路由与上传均需登录；session 为 httpOnly。
- 部署：`output: 'standalone'` + Docker Compose + Caddy HTTPS；数据卷持久化 `content/`、`public/uploads/`、SQLite 目录。响应头避免反向代理缓冲流式输出（如 `X-Accel-Buffering: no`）。
- 发文后 `revalidatePath`，不要靠整站重建让新文章可见。

## 10. 明确不做（第一版）

评论、邮件订阅、多用户、修改 slug、后台编辑关于页、独立 Umami/Postgres、CDN、文章内 JSX、正文原始 HTML、删除文章时的回收站、级联删除 `public/uploads/` 图片。
