## 相对 v1 的行为变更

| 项 | v1 | V2 |
|---|---|---|
| 登录后导航 | 顶栏 | 左固定侧栏 |
| `/admin` 筛选 | 无 | `?status=`：全部 / 已发布 / 草稿 / 存档 |
| `/admin` 浏览列 | 无 | 已发布与存档显示累计 PV；草稿显示「—」 |
| `/admin` 删除 | 文案写过可删 | 列表不提供删除，只在编辑页 |
| 统计「各篇文章」 | 仅已发布 | 草稿、已发布、存档都列出，并显示状态 |
| 统计热门 | Top 10 已发布，链到前台正文 | 仍是已发布 Top 10；标题链到后台编辑页 |
| 今日浏览 | 无 | 上海时区当日、按现有计入规则的真实次数 |
| 编辑器文稿栏 | 始终展开在正文上方 | 左侧约 280px，可收起 |

不改：单管理员、评论、订阅、批量、多选、搜索、分页、图表、富文本、改 slug、后台改关于页、PV 的计入对象（仍只记访客成功打开的已发布正文，管理员 session 不记）。

## 壳（登录后）

路由：`/admin`、`/admin/posts/new`、`/admin/posts/[slug]`、`/admin/stats`。`/admin/login` 不用这层壳。

- 左栏约 220px，白底、右边线。品牌为 `getSiteConfig().name` 的衬线字，旁加弱角标「后台」。品牌链到 `/admin`。
- 导航三项，带 16px 线性图标：文章 → `/admin`；写文章 → `/admin/posts/new`；统计 → `/admin/stats`。
- 选中：软底 + pine 色字 + 左侧 pine 条。`/admin` 精确匹配「文章」。`/admin/posts/new` 与 `/admin/posts/[slug]` 都算「写文章」。`/admin/stats` 算「统计」。
- 底栏分隔线以下：前台、主题、登出。
- 前台链到 `/`，新标签打开，`rel="noopener noreferrer"`。
- 主题是浅色/深色切换，沿用现有 `next-themes`，按钮上要有「主题」二字。
- 登出走现有登出 action，清 session 后回登录页。不要做成链到登录页的假链接。
- 主区纸色，独立滚动。编辑器路由改为铺满剩余高度，由文稿栏、Markdown、预览各自滚动。
- 无访客头像，无站内搜索图标，无访客顶栏那套导航。
- 窄于 768px：侧栏改为顶部紧凑条（品牌、三项导航、前台 / 主题 / 登出），避免 220px 侧栏把主区挤没。原型没画窄屏，按这条最小可用，不另做一套视觉。

## `/admin/login`

- 全视口左右分栏。左约 45%：纸色加淡 pine 晕染，衬线站名、「写作后台」、短句「安静写字，清晰管理。」、一行「单管理员工作台」、页脚域名或站名。无库存图。
- 右：白底，「登录后台」、说明「使用管理员账号进入工作台」、用户名、密码、通栏 pine「登录」。
- 左下或表单下「← 返回前台」链到 `/`。
- 窄于 768px 隐藏左栏，只留表单。
- 已登录访问登录页仍进 `/admin`。密码错误仍是笼统中文，显示在字段下，不区分用户是否存在。

## `/admin` 文章总览

- 衬线标题「文章」，旁为当前筛选下的篇数（「N 篇」）。右上一个 pine 按钮「写文章」→ `/admin/posts/new`。统计入口只留在侧栏。
- 筛选 chips：全部 | 已发布 | 草稿 | 存档。一项选中。用查询参数 `status=published|draft|archived`；缺省或非法值当作全部。刷新后筛选还在。
- 表：标题 | 日期 | slug | 状态 | 浏览。白底、行悬停软底。标题链到 `/admin/posts/[slug]`。
- 状态文案：已发布、草稿、存档。pill：已发布软 pine，草稿中性，存档更淡。
- 浏览：已发布与存档显示该 slug 累计 PV（0 也显示 0）；草稿固定「—」。一次查出全部计数，不要按行查库。
- 无文章：「还没有文章。从「写文章」开始。」筛选结果为空：说明这个状态下还没有文章，并保留 chips。
- 无搜索、无分页、无多选、无行内删除。

## 编辑器

新建 `/admin/posts/new` 与编辑 `/admin/posts/[slug]` 共用这一版工作面。原型只画了「编辑已发布」，按钮仍按 v1 状态机，不能四颗按钮永远一起出现。

顶栏（主区内，不进侧栏）：

- 左：「← 文章」回 `/admin`，当前标题（跟表单标题走，空则「未命名」），已保存状态的 pill。新建页不显示状态 pill。
- 右，按状态：
  - 新建或草稿：次「保存草稿」，主「发布」。无存档、无删除。
  - 已发布：主「保存」，次「改为草稿」，弱「存档」，分隔线后危险「删除」。
  - 已存档：主「保存」（仍为存档），次「改为草稿」，危险「删除」。无「发布」，无再次存档。
- 存档、删除仍须现有中文确认。删除后回 `/admin`。进行中按钮禁用并改成「保存中…」「删除中…」。

左栏「文稿信息」约 280px，可收起。收起后面板隐藏，写作区变宽；按钮变为「展开」。刷新后默认展开，不写入本地存储。

字段与现在相同，只是挪进这栏：slug、日期、标题、标签、摘要、封面（路径或 https +「选择图片」+ 现有预览与外链失败说明）、精选（文案用「精选」）。编辑时 slug 只读，说明「创建后不可改」。新建时 slug 可填，规则仍是 `[a-z0-9-]+`，第一次保存后变成「手填-序号」。

右侧桌面为 Markdown | 预览分栏，预览继续走现有 Markdown 渲染，衬线气质跟访客正文。拖拽、粘贴、选择图片插入正文保留。空预览有中文占位。

窄于 1024px：文稿信息在上，Markdown 与预览上下叠，不并排三栏。

不存在的 slug：后台 404。

## `/admin/stats`

- 衬线「统计」。说明：仅统计访客打开已发布正文；管理员访问不计入。无图表。
- KPI 三格：总浏览、已发布篇数、今日浏览。数字为 0 时显示 0。
  - 总浏览：现有 `post_views` 合计。删文后该 slug 的累计从总数去掉。
  - 已发布篇数：状态为已发布的文章数，不含草稿与存档。
  - 今日浏览：`Asia/Shanghai` 自然日、按现有 `recordPostView` 规则新记下的次数。与总浏览同一写入路径加一条日累计（按日一行即可，不必按文章拆今日）。上线前的历史无法回填，从部署后开始计。删文不回退当日已发生的次数。
- 「热门文章」：已发布 Top 10，按浏览降序。序号、标题、次数。无记录时中文空状态。标题链到编辑页。
- 「各篇文章」：全部文章。列：标题、日期、状态、浏览。排序：有数字的按浏览降序，相同则日期新的在前；草稿排在后面，浏览列「—」。标题链到编辑页。一篇都没有时中文空状态。KPI 行仍然显示。
