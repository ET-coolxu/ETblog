# 后台编辑关于页

本文取代 [v1](v1.md) 里这些句子中的关于页部分：

- 「关于页仅本地编辑，第一版后台不提供入口」
- 「管理员不能在后台改关于页」
- 「后台只管文章……关于页只用本地文件」里的关于页部分

本文取代 [后台工作台 V2](v2-admin.md) 里「导航三项」「不改：后台改关于页」，以及窄屏「三项导航」。侧栏改为四项，窄屏顶部紧凑导航同样带上「关于」。

没写到的行为仍按更早文档里尚未被取代的条目。v1「机器发文不改关于页」仍然有效。[访问记录](v3-visits.md) 的计入范围和统计页不改。

## 本期要做

后台侧栏增加「关于」。顺序：文章、写文章、关于、统计。

选中：`/admin` 精确匹配「文章」；`/admin/posts/` 只算「写文章」；`/admin/about` 算「关于」。图标沿用侧栏已有的 16px 线性图标。

`/admin/about` 放在现有登录壳里。打开时用现有读取把 `content/pages/about.md` 放进一个文本框；文件不存在时框为空。一个保存按钮。成功后用简体中文说明前台已更新；失败显示中文错误。

保存写回这份固定文件，路径用代码里已有的常量，不从浏览器接收路径。写入前去掉 BOM 和末尾空白。去掉首尾空白后没有正文，写成空文件。公开页对空内容仍显示「尚未填写关于页」。去掉首尾空白后以 `---` 开头则拒绝保存，提示不要写成 frontmatter，且不改磁盘。整文件就是正文，不自动包一层 frontmatter。

保存用 Server Action。写盘前再验一次管理员 session。成功后只刷新 `/about` 和 `/admin/about`，不调用文章那套整批刷新，不整站重建。

关于页仍是这一份普通 Markdown。页标题「关于」继续写在公开页组件里，不写进文件。作者可在正文里手写 Markdown，包括已有的图片语法。

## 本期不做

关于页上的预览、插图按钮、富文本、草稿、发布、存档。不使用文章的标题、slug、日期、标签、封面。机器发文和 MCP 不改关于页。不改公开页版式、访问记录和文章编辑。
