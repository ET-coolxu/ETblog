## 提示词正文

你是本仓库（ET blog）的实现助手。目标：做 V3.1，让管理员在后台改关于页正文。不扩大到文档没写的能力。

## 本次需求

用户说的是「现在开始做 V3.1」。V3.1 只做这一件事：后台侧栏增加「关于」，打开 `/admin/about`，用一个文本框修改 `content/pages/about.md`，保存后前台 `/about` 更新。

关于页仍是这一份普通 Markdown。页标题「关于」继续写在公开页组件里，不写进文件，正文里也不要再加一遍。不做草稿、发布、存档，也不使用文章的标题、slug、日期、标签、封面。

侧栏顺序改为：文章、写文章、关于、统计。窄屏顶部那条紧凑导航同样带上「关于」。选中规则：`/admin` 仍只算「文章」；`/admin/posts/` 仍只算「写文章」；`/admin/about` 算「关于」。图标沿用侧栏现有的 16px 线性图标，在同一组件里加一枚，不引入新的图标库。

编辑页：

- 打开时用现有的 `getAboutSource()` 把文件内容放进文本框。文件不存在时框为空。
- 一个保存按钮。成功后用简体中文说明前台已更新；失败显示中文错误。
- 保存写回固定路径 `content/pages/about.md`。路径用代码里已有的常量，不从浏览器接收路径。
- 写入前去掉 BOM 和末尾空白。去掉首尾空白后若没有正文，写成空文件。公开页对空内容仍显示「尚未填写关于页」。
- 正文以 `---` 开头时拒绝保存，并提示不要写成 frontmatter。公开渲染会把这种开头吃掉。
- 整文件就是正文，不要自动包一层 frontmatter。
- 保存成功后只 `revalidatePath("/about")`，并刷新 `/admin/about`。不调用文章那套整批刷新，不整站重建。

页面放在现有后台登录壳里。保存用 Server Action，写盘前再验一次管理员 session。

机器发文和 MCP 仍然不改关于页。公开页的版式、访问记录、文章编辑都不改。

本期不做：关于页上的预览、插图按钮、富文本、草稿、发布、存档。作者仍可在正文里手写 Markdown，包括已有的图片语法。

## 相关材料

- 需求文档：现在开始做 V3.1。访问记录仍以 `docs/requirements/` 里现有的 v3 为准。文章状态、slug、上传、谁计入 PV，仍以 v1 里尚未被取代的条目为准。后台壳的视觉仍以 v2 为准，但本版取代其中「导航三项」和「不改后台改关于页」。v1 里「关于页仅本地编辑、后台不提供入口」「管理员不能在后台改关于页」由本版取代。v1 里「机器发文不改关于页」仍然有效。不要把需求文档的文件名写进长期规则。
- 相关路径：`components/admin-sidebar.tsx`、`lib/posts.ts`、`app/(site)/about/page.tsx`、`app/admin/(dashboard)/layout.tsx`、`app/admin/(dashboard)/posts/actions.ts`、`docs/架构/项目架构.md`、`README.md` 首段、`.cursor/rules/project.mdc`
- 截图或参考：无。编辑页不要套文章编辑器那一页。

## 验收标准

- 已登录后台能看到侧栏「关于」，位于「写文章」和「统计」之间。点进去是 `/admin/about`，文本框里是 `content/pages/about.md` 的现有正文
- 改几句并保存后，再打开前台 `/about`，正文已更新。页标题仍是「关于」
- 把正文清空并保存后，前台显示「尚未填写关于页」
- 正文以 `---` 开头时保存失败，文件内容不变，页面上有中文错误
- 未登录不能打开 `/admin/about`，也不能把内容写进这个文件
- `/admin` 仍只高亮「文章」，文章编辑页仍只高亮「写文章」，`/admin/about` 高亮「关于」
- 文章的新建、编辑、发布，以及 Publish API，都不改 `about.md`
- 统计页访问记录、总浏览和今日浏览的计入方式不变
