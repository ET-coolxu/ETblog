## 提示词正文

你是本仓库（ET blog）的实现助手。目标：在现有后台统计上增加基本访问记录和独立访客数，不扩大到文档没写的能力。

## 本次需求

在 `/admin/stats` 保留现有统计，并增加访问记录和按 IP 去重的独立访客。

现有三块保持原语义，数字为 0 时仍显示 0：

- 总浏览：`post_views` 合计。删文后该 slug 的累计从总数去掉。
- 已发布篇数：状态为已发布的文章数。
- 今日浏览：`Asia/Shanghai` 自然日、访客成功打开已发布正文的次数。管理员 session 不记。删文不回退当日已发生的次数。
- 「热门文章」和「各篇文章」的列、排序、空状态、标题链到编辑页，都保持现状。

新增两格，放在现有 KPI 旁。上线前的访问无法回填，从这次部署之后开始计：

- 今日独立访客：上海时区当天，访问记录里不重复的 IP 数。
- 累计独立访客：访问记录里不重复的 IP 数。

同一 IP 刷新多次，访问记录有多行，独立访客只算 1。

访问记录记这些公开页，且页面成功打开之后才记。带管理员 session 不记。失败只打日志，不抛给访客，也不要为此新增公开的统计接口。

- `/`：首页
- `/posts`：文章列表
- `/posts/[slug]`：仅已发布正文。草稿、存档、不存在的 slug 不记，与现在 `recordPostView` 的条件一致。这一次打开仍照旧给 `post_views` 和 `daily_views` 加 1，并同时写一行访问记录。
- `/about`：关于

标签页、搜索页、后台页面不记。首页、文章列表、关于只写访问记录，不加进总浏览和今日浏览。

每条记录保存：时间、页面、完整 IP、来源。来源为空时显示「直接访问」。来源过长可以截断后再存。时间按上海时区显示到分钟。页面列：首页、文章列表、关于用这三个中文名；正文用文章标题，标题链到该文编辑页。文章后来被删了，这一行仍保留，页面列改为当时的路径，不要链接。删文不删除、不改写已有访问记录。

IP 显示完整地址，IPv4 和 IPv6 都要能存。只出现在已登录的统计页，不出现在公开页面、RSS 或接口响应里。生产环境经 Caddy 反代，客户端 IP 取可信代理转发的地址；本机直接访问则用连接上的地址。

统计页在现有表格下方加「访问记录」。列：时间、页面、IP、来源。按时间从新到旧。每页 20 条，用页码或上一页 / 下一页翻更早的记录，刷新后仍停在当前页。没有记录时用中文空状态，不显示分页。只有一页时不必给出可点的翻页。这一张表可以分页；后台其他列表仍然不做分页、搜索、多选、批量或图表。

页顶说明改成能同时覆盖两套数字：总浏览和今日浏览仍是已发布正文；独立访客和访问记录还包括首页、文章列表和关于。管理员访问不计入。

## 验收标准

- 未登录打开首页、`/posts`、一篇已发布正文、`/about` 后，统计页访问记录各多一行，含上海时间、页面、完整 IP、来源；无来源时为「直接访问」
- 同一 IP 再打开这些页面，记录继续增加，累计独立访客不加
- 上海时区当天的新 IP 使今日独立访客加 1；过了上海时区零点后，今日独立访客按新的一天重计，累计独立访客不回退
- 已发布正文的这一次打开，总浏览和今日浏览仍加 1。首页、文章列表、关于不加进这两个数
- 草稿、存档、不存在的正文、标签页、搜索页、带管理员 session 的访问，都不产生访问记录，也不增加独立访客
- 访问记录每页 20 条，最新在前，可以翻到更早的记录。后台文章列表和其他统计表仍然没有分页
- 删除文章后，该文的总浏览从合计去掉，已有访问记录还在；热门文章和各篇文章的现有行为不变
- 公开页面上看不到 IP 和访问记录
- 统计写入失败时，访客页面仍正常打开
