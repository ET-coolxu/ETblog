- 列表标题：`components/post-index.module.css` 的 `.title`，`components/post-card.module.css` 的 `.title`，`components/home-feed.module.css` 的 `.leadTitle`、`.rowTitle`、`.latestTitle`。`.latestTitle` 若现在是 500，改回 400
- 顶栏站名：`components/site-header.module.css` 的 `.brand`
- 页题：`app/styles/shared.css` 的 `.doc-title`，`components/post-index.module.css` 的 `.pageTitle`，`components/home-feed.module.css` 的 `.sectionTitle`，`app/(site)/about/page.module.css` 的 `.title`，`app/(site)/tags/page.module.css` 的 `.title`，后台文章列表、统计、登录页各自的 `.title`，以及 `app/not-found.tsx`、`app/(site)/not-found.tsx` 里页题上的 `font-sans`（改成 `font-serif`，字号类不动）

`app/(site)/tags/page.module.css` 若在宽屏把 `.title` 设成 `font-weight: 600`，这是页题，改回 400，或删掉这条覆盖。只改这些标题的 `font-family` 和上述字重，不要改它们的字号、行高、字距、颜色。

正文、导航、日期、标签、摘要、kicker、页脚、后台表单、目录仍用 `--font-sans`（Noto Sans SC）。导航、标签、页脚、kicker、部分日期上现有的 500 和 600 不要改。引用仍用 `--font-serif`，保留 `font-synthesis: none`。登录页 `.motto` 和统计页 `.kpiValue` 已经是衬线，字号和字重不动。

改完后的加载：

- 构建期不访问 Google Fonts。用 `next/font/local`。不要用 `next/font/google`。
- 无衬线、衬线各一个 woff2、各一次 `localFont`。只选 Noto Sans SC 与 Noto Serif SC，不要再下思源，也不要单独托管 Inter 或 Newsreader。拉丁字形用这两套中文字体自带的拉丁。
- 实现者必须先核对许可证（允许随仓库分发，OFL 即可）、字重轴和体积，再把文件放进 `app/fonts/files/`。优先可变字体。字重轴至少覆盖站点真正用到的 400 与 500。引用若仍是 300，文件要能覆盖 300；否则把引用字重改成该文件最细的真实字重，并在回复里说明。无衬线侧若轴能覆盖现有的 600，那些 600 就用真实字重；覆盖不了不要为 600 再加文件，也不要改导航和标签的 600，在回复里说明。
- 单个 woff2 超过 2MB 不入库。下载前先核对体积；超过 2MB 就不要把该文件放进仓库或留在工作区，该角色退回下面的当前系统字体栈，在回复里写明字节数和退回原因，然后继续另一个未超限的角色。禁止再按 unicode-range 拆成几十个 `localFont`，禁止恢复 `vendor-local-fonts.py`。退回时不要把未定义的 `var(--font-noto-*)` 留在 `font-family` 最前面，否则整条声明会失效。

```css
--font-sans: "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei",
  "Noto Sans CJK SC", sans-serif;
--font-serif: "Songti SC", "SimSun", "Noto Serif CJK SC", serif;
```

两个文件都合格时，新建 `app/fonts/index.ts`，只保留两次 `localFont`。`weight` 换成文件真实字重轴，不要照抄 `300 600`：

```ts
import localFont from "next/font/local";

const notoSans = localFont({
  src: "./files/noto-sans-sc.woff2",
  weight: "400 500",
  display: "swap",
  preload: false,
  adjustFontFallback: false,
  variable: "--font-noto-sans",
});

const notoSerif = localFont({
  src: "./files/noto-serif-sc.woff2",
  weight: "400 500",
  display: "swap",
  preload: false,
  adjustFontFallback: false,
  variable: "--font-noto-serif",
});

export const fontVariableClassName = [notoSans, notoSerif]
  .map((font) => font.variable)
  .join(" ");
```

`adjustFontFallback` 必须是 `false`。打开后 Next 会把 Arial 或 Times 插进字体栈，汉字会被挡住。`preload` 必须是 `false`。`display` 必须是 `swap`。给这次新增的导出写一句中文注释，说明为什么 fallback 关闭、为什么变量要挂在 `body` 上。

`app/layout.tsx` 保留 `generateMetadata` 和 `ThemeProvider`，把 `fontVariableClassName` 挂到 `<body>`。不要换成写死的标题和描述。

字体栈写在 `body` 上，与这两个变量同一元素。现在它们在 `:root` 里；挂上 `next/font` 之后若仍写在 `:root`，变量是空的。从 `:root` 移到 `body`，其它令牌留在 `:root`。网页字体写在系统字体前面：

```css
--font-sans: var(--font-noto-sans), "PingFang SC", "Hiragino Sans GB",
  "Microsoft YaHei", sans-serif;
--font-serif: var(--font-noto-serif), "Songti SC", "SimSun", serif;
```

写反了的话，Windows 雅黑会截住后面的网页字体。保留 `--font-sans`、`--font-serif` 这两个名字。

不再使用 Newsreader。引用上残留的 `font-optical-sizing: auto` 和「拉丁仍用 Newsreader」的注释删掉。不要在标题或列表上把 `font-optical-sizing` 加回来。引用的 `font-synthesis: none` 保留，避免中文被合成斜体。
