# 字体

全站只有两个字体角色：`--font-sans` 和 `--font-serif`。组件只引用这两个名字，不写具体字体文件。字号、字重、行高和字距在 `app/styles/tokens.css`。

## 加载

`app/fonts/index.ts` 用 `next/font/local` 各加载一次：

| 角色 | 文件 | 字重轴 | 覆盖 |
| --- | --- | --- | --- |
| 无衬线 | `app/fonts/files/noto-sans-sc.woff2` | 100–900 | GB2312（6763 字）和拉丁 |
| 衬线 | `app/fonts/files/noto-serif-sc.woff2` | 200–900 | GB2312 一级常用字（3755 字）和拉丁 |

两个文件都是可变字体，`display: swap`，`preload: false`，`adjustFontFallback: false`。fallback 必须关闭，否则 Arial 或 Times 会插进字体栈，挡住后面的汉字。

生成的变量挂在 `body` 的 class 上。`--font-sans` 和 `--font-serif` 也写在 `body` 上，和这两个变量同一元素；写在 `:root` 里解析不到。网页字体放在系统字体前面，否则 Windows 上的微软雅黑会截住后面的网页字体。

```css
--font-sans: var(--font-noto-sans), "PingFang SC", "Hiragino Sans GB",
  "Microsoft YaHei", sans-serif;
--font-serif: var(--font-noto-serif), "Songti SC", "SimSun", serif;
```

衬线文件没有的汉字落到宋体。无衬线没有的汉字落到苹方、冬青或微软雅黑。构建期不访问 Google Fonts。

`body` 默认无衬线、`--text-base`（1rem）、行高 1.5。`h1`–`h4` 继承字号和字重，各级标题在组件里单独指定。

## 两个角色怎么分

衬线用于需要被看成标题的文字：顶栏站名、页题、文章标题、正文小标题、列表标题、引用，以及统计里的大数字。字重用文件里真实的 400。引用用 300，并设 `font-synthesis: none`，避免中文被合成斜体。

无衬线用于正文、导航、日期、标签、目录、表单、页脚和代码。代码是 `font-family: inherit`，跟正文同一套无衬线，不用等宽字体。导航、标签和页脚上的 500、600 落在无衬线的 100–900 轴里，是真实字重。

后台侧栏站名和登录页左侧站名是无衬线，和公开顶栏的衬线站名不同。编辑器预览里的文章标题也是无衬线。

## 字号

根字号 16px。下表是各级实际使用的刻度。

| 变量 | 尺寸 | 用于 |
| --- | --- | --- |
| `--text-2xs` | 0.6875rem | 页脚、首页日期和标签、文章标签 |
| `--text-hint` | 0.75rem | 标签计数 |
| `--text-xs` | 0.8125rem | 导航、文章元信息、目录、分页 |
| `--text-sm` | 0.875rem | 摘要、说明、后台正文级文字 |
| `--text-md` | 0.9375rem | 标签名、后台侧栏站名 |
| `--text-base` | 1rem | 全站默认、列表 |
| `--text-prose` | 1.125rem | 文章正文 |
| `--text-lg` | 1.125rem | 关于页 H3 |
| `--text-xl` | 1.25rem | 顶栏站名、列表标题、关于页 H2 |
| `--text-2xl` | 1.5rem | 首页区块题、首页行标题、未找到页 |
| `--text-h3` | 1.375rem | 正文 H3 |
| `--text-quote` | 1.5rem | 引用 |
| `--text-h2` | 1.75rem | 正文 H2；窄屏文章标题 |
| `--text-3xl` | 1.875rem | 首页主标题、`.doc-title`、统计数字、登录页题 |
| `--text-page` | 2rem | 文章列表页题、标签页题 |
| `--text-display` | 2.5rem | 宽屏文章标题（≥768px） |

关于页页题单独用 1.9375rem，正文用 1.0625rem，不走上表变量。

## 文章正文

正文容器是 `.markdown`，后台预览共用这一层。

| 文本 | 角色 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- | --- |
| 段落 | 无衬线 | `--text-prose` | 继承 | `--leading-prose`（1.95rem） |
| H2 | 衬线 | `--text-h2` | 400 | `--leading-h2`（2.4rem） |
| H3 | 衬线 | `--text-h3` | 400 | `--leading-h3`（1.9rem） |
| 列表 | 无衬线 | `--text-base` | 继承 | `--leading-7` |
| 引用 | 衬线，斜体，关闭合成 | `--text-quote` | 300 | `--leading-quote`（2.35rem） |
| 表头 | 无衬线 | `--text-xs` | 500 | — |
| 单元格 | 继承正文 | `--text-sm` | 继承 | 1.5rem |
| 行内代码与代码块 | 继承正文的无衬线 | 行内 0.9em；代码块 `--text-sm` | 继承 | 代码块 1.7 |

H2、H3 使用 `--tracking-title`（-0.01em）。

关于页正文不走 `.markdown`：正文无衬线 1.0625rem、行高 1.75；H2 衬线 `--text-xl`、H3 衬线 `--text-lg`，字重都是 400。
